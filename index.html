Predicting Barbell Lift Quality

Mrunmayi A Bhave | Practical Machine Learning course project

Goal and data

Accelerometer measurements from the belt, forearm, arm, and dumbbell are used to classify how each exercise was performed. The target classe has five categories: A through E. The supplied training data contain 19622 labeled observations. The separate quiz file contains 20 unlabeled cases.

The outcome classes are imbalanced, so validation folds were stratified. Rows and columns identifying a participant, timestamp, window, or record number were excluded to avoid relying on administrative identifiers. I retained 52 numeric sensor features that vary and have no more than 10% missing values. The selected predictors had no remaining missing values in these data.

Model and validation

I used a random forest classifier. Each forest combines many classification trees fitted to bootstrap samples; at each split it considers a random subset of predictors. The default square-root rule gives mtry = 7. I used 250 trees per validation fit and 500 trees for the final model to stabilize predictions. Participant and time fields were omitted because they describe data collection rather than movement quality.

To estimate generalization error, I assigned observations within each class to five folds, trained on four folds, and predicted the held-out fold. Each labeled observation received one out-of-fold prediction. The pooled error is the fraction of all out-of-fold predictions that are incorrect.

Quiz predictions and reproducibility

After validation, I fit the same model settings to all labeled training rows and predicted the 20 quiz cases in their supplied order. The predictions are in quiz_predictions.txt (one class per line) and quiz_predictions.csv (numbered rows).

To reproduce the model and predictions, run Rscript analysis.R from the project directory. The script fixes the random seed, performs the stratified cross-validation, fits the final forest, and writes the prediction files and model results. The report source is model_report.Rmd.

Data source: Groupware at PUC-Rio, Weight Lifting Exercise Dataset, project dataset page. The data were generously made available for this course assignment.
